The guide teaches libstb one function at a time. Every lesson has the same example in C++ and in Python, the
pictures that example produces, and the benchmark numbers for it.

The two API references stay where they are: the **Python reference** (Sphinx) and the **C++ reference** (Doxygen) are in the
top bar, and every lesson links to the same function in both. The [benchmarks](/benchmarks) have their own page.

Choose a language tab once; it is remembered on every page, including the home page.

Start with [Resize](./image/resize).
