libstb reads, resizes, draws on and writes images, and renders text, from C++ and from Python.

This site is the teaching layer. Every lesson is one page per function, with the same example in both
languages, the pictures that example produces, and the benchmark numbers. The two API references stay
where they are: the **C++ reference** (Doxygen) and the **Python reference** (Sphinx) are in the top bar,
and every lesson links to the same function in both.

Choose a language tab once; it is remembered on every page.

Start with [Resize](./image/resize).
