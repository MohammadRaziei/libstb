<pre data-lang="bash" data-label="bash">pip install libstb</pre>
<p class="install-note">Python 3.9+ and nothing else: libstb has no runtime dependencies. It shares memory with numpy and with DLPack consumers such as torch, and converts to and from Pillow, so there is nothing to translate by hand. Add the extra of the library you pair it with: <code>pip install "libstb[numpy]"</code> or <code>"libstb[pillow]"</code>. Wheels ship a pre-built native extension for Linux, macOS and Windows. For the latest development build: <code>pip install git+https://github.com/MohammadRaziei/libstb</code></p>
